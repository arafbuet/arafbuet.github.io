How I Work

A clear, repeatable process from brief to final delivery.

1. Brief

You share the problem, study area, data you have, desired outputs, timeline, and budget. I ask clarifying questions and confirm scope.

2. Plan

I propose a method (sensors, classification approach, validation), deliverables list, file formats, milestones, and revision policy — then we agree.

3. Delivery

I execute the workflow, run quality checks (accuracy assessment, visual inspection), package all files with metadata and a short methods note, and deliver via agreed channel.

4. Revisions

Two rounds of revisions are included. Additional rounds or scope changes are scoped separately. Final files are re-delivered with updated metadata.

Featured Work

Selected research and freelance projects demonstrating geospatial and analytical capabilities.

Sundarbans LULC Mapping — Google Earth Engine & Python

Problem
Quantify multi-decadal land-cover change in the Sundarbans mangrove ecosystem and identify high-value conservation hotspots for decision support.
Method
5-class supervised classification (Water, Aquaculture, Settlement, Vegetation, Agriculture) on annual Landsat/Sentinel composites; multi-year change detection; ecosystem service valuation (ESV) per class; Getis-Ord Gi* hotspot analysis on 1 km grid; reproducibility via GEE and Python (Microsoft Planetary Computer STAC).
Tools
Google Earth Engine (JavaScript API), Python (Microsoft Planetary Computer STAC: Landsat C2L2, Sentinel-1 RTC, JRC-GSW, Copernicus DEM, Hansen/GHSL/ETH canopy), ArcGIS Pro 3.1 for map layouts.
Output
Classified GeoTIFFs per year, ESV rasters, Gi* z-score and significance maps, transition matrices (km²/ha), accuracy assessment (OA 0.91/0.95 on smoke test), reproducible GEE scripts and Python modules, A4 map layouts.

Bangladesh Crop Pattern AI Project — IWFM, BUET

Problem
Map seasonal crop types nationwide to support hydrological modeling and water-demand estimation.
Method
Time-series analysis of Sentinel-1 and Sentinel-2; machine learning classification (Random Forest, CNN) for seasonal crop patterns; integration with hydrological modeling for water-demand estimation.
Tools
Google Earth Engine, Python, Sentinel-1/2 time series, Random Forest, CNN architectures.
Output
Crop type maps, classification models, integrated water-demand estimates, collaborative research outputs under IWFM Water Resources Development program.
